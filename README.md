# ProdTrack_Node

**ESP32-Based Real-Time Production Tracking Board**

## Overview

ProdTrack_Node is an ESP32-based hardware platform designed for real-time production monitoring and traceability in industrial environments.

The board integrates RFID identification, a push button for operator interaction, and two status LEDs for visual feedback. It enables the collection and wireless transmission of production-related events to external monitoring systems.

## Key Features

- **ESP32 Microcontroller** – Processing, system control, and wireless connectivity.
- **RFID Interface** – Contactless identification and production traceability.
- **Push Button** – Manual operator interaction and event registration.
- **Dual Status LEDs** – Visual indication of system and operation status.
- **Wireless Communication** – Support for real-time data transmission through ESP32 connectivity.
- **Compact Design** – Suitable for integration into production workstations.

## Applications

- Real-time production monitoring
- Industrial process traceability
- Manufacturing workstation tracking
- RFID-based identification
- Production event registration
- Smart manufacturing and Industry 4.0 systems
